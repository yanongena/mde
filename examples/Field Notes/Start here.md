# A little room to think.

Welcome to **Margin**. A quiet place for your notes, your code, and the work that connects them.

This is an ordinary Markdown file. Your folder is your workspace. Open it in another editor at any time.

## Make yourself at home

- [ ] Capture an idea in a new note
- [ ] Paste a screenshot with **Ctrl+V** (⌘V on Mac)
- [ ] Move a note and watch its links follow
- [ ] Open a real terminal with the **+** button in the bottom panel
- [x] Find a little space for focused work

## Words and work, together

The visual toolbar keeps Markdown syntax out of your way. Use **Source** whenever you want to see the file underneath.

| In the margin | In the workspace |
| --- | --- |
| Ideas & notes | Ordinary Markdown files |
| Screenshots | Portable relative image paths |
| Small scripts | A proper code editor |
| Commands | A real system shell |

> Good tools leave a little more room for the thing you came to do.
