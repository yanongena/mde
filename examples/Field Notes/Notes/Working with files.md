# Working with files

Every note in this folder is a plain UTF-8 Markdown file.

## A safe way to reorganize

Right-click a file or folder in the explorer, then choose **Rename / move**. Enter a path relative to the workspace. You can also drag items onto a folder or into an empty part of the explorer to move them to the root.

Margin updates standard Markdown links and image references throughout the workspace. Save open edits before moving files. Source documents, destination documents, spaces, anchors, reference definitions and nested folders are handled together.

The [welcome note](../Start%20here.md#make-yourself-at-home) links here. Try renaming this note, then visit the welcome note again.

## Attachments

Preferences lets you choose a shared workspace folder, a custom folder inside the workspace, or a folder beside each note. Paste images into a visual note, choose the image toolbar button, or drag a PNG, JPEG, GIF or WebP into the document.

## When files change outside Margin

Clean tabs reload automatically. A file with unsaved edits gets a visible conflict banner. Compare both versions and save a recovered copy, or explicitly reload the disk version. Closing the app also offers to retain unsaved recovery drafts.
